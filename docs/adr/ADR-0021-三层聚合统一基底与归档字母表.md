# ADR-0021:三层聚合统一基底与归档字母表

## Context

三实践仓各自跑 distil-skill 后长出三种形态:ai-ccoe 仓根三层单仓提交分层、pve-harness docs 中心全家桶单仓路径级回滚(ADR-0007 用户裁定)、browse_rs 未建以 diary 等价形在主仓。同标准三种解且词汇趋同(ADR/REQ/R/G/M/P/S/diary)而归位互异(pve R002 与 ai-ccoe G003 同题异前缀)。用户裁定(2026-10-10):四仓达成一致对齐修成一个标准,三实践仓为灯塔判例;比标准更好的实践回流改进标准;doc-gov 与 sources 统一;三层知识项目级自持。经三仓反馈单(16 坑 10 提案)、讨论轮(13 处改法)、grok-01 业界对照(Voyager、Mem0 两代、Letta MemFS、cognee、agentskills spec、Diátaxis、MADR、skill-creator、WikiSkill 论文 arXiv 2608.27454 且仓内 S014 已对照),草案 v2 冻结。

## Decision

三层聚合统一基底定形,条款如下(细则以轮次档草案 v2 与两 skill 终态文本为准):

- **sources 层扩为唯一出处层**:自产轨迹、自产证据件(REQ trace、工件包、门禁输出、回执)、外档信源原档统一收口,一层一索引盖全根,只增不改;项目级自持,跨仓材料以 sources/external 内嵌链接与 verbatim 留底承载,不设跨仓共享知识库
- **证据分级 relation 两根词**:derived_from(自产)撑模式页辖资格过滤,cited_source(外档)撑综述与研究结论页;细分词留仓内白名单,白名单收 supersedes;新轨迹否定旧模式走新版本或 supersede,不原地改写
- **git 形态三选一**:分仓 / 分目录分 git(外层 .gitignore 登记加门禁豁免声明)/ 单仓纪律形(提交分层加路径级回滚纪律两操作件;knowledge 先于闸门提交、永不回滚);排除 agent 记忆库内嵌技能形(技能与记忆同一 git)
- **归档统一字母表八元组**:ADR(knowledge/adr)、REQ(knowledge/req,弃 requirements 名)、R(knowledge/references)、G(operations 标准手册,只收 how-to,Diátaxis 判据)、M(knowledge/mistakes)、P(sources/evidence 判例)、S(knowledge/research 页加 sources/external 原档)、diary(sources/diary);前缀混挂走退役不复用律;tutorial 不进标准层
- **doc-gov 工件归层**:ADR/REQ = knowledge 页型;研究档案一题一篇,结论页在 knowledge、原档在 sources、编号跨层;辖域为三层聚合仓,纯 doc-gov 仓形态不变;ADR 保持 Nygard 三段,不换 MADR 全模板
- **operations 边界与加载视图**:收标准技能与 how-to 手册两类,皆过闸;operations 层根收两类,.claude/skills 是技能子集的加载视图(符号链接或投影加同步守卫),常驻面只有 frontmatter 的 name 与 description,手册不进安装路径;执行回合不整层注入 knowledge(执行者读知识层实证降效,WikiSkill 5.1)
- **闸门证据形态扩**:门禁集与点名义务同轮首点名,点名后不收窄,重门禁可记当轮不适用;本地 hook 拦截属谓词 1 证据;证据全为确定性命令可免隔离轮,含 agent 行为(技能触发等)必须隔离跑,触发面落成可复跑触发对(负例取近失),不引 pass rate 与均值闸;标准页头闸门记录段加回指行(技能指回促成它的模式页)
- **取样窗口非保留期**:窗口缺省最近 1 至 3 日,建仓首轮收口豁免;已入库 sources 与知识页不因出窗失效
- **CoALA 映射注**:sources 约 episodic、knowledge 约 semantic、operations 约 procedural,会话上下文约工作记忆不进三层,外档靠 relation 类型判别不设第四层
- **业界负对照排除**:不引向量 top-k 技能库与自检即入库(Voyager)、不引严格变好均值闸(WikiSkill 式 (4) 与 Hermes 同形门)、不引无痕推断边(cognee)、不引免人裁巩固(Letta dreaming)、不建跨仓共享记忆服务

## Consequences

- 好:三灯塔仓与标准文本互为镜像,一字母一归层可判;单仓项目不再被迫停工问裁(第三 git 形入标);业界踩过的坑(触发测量、均值闸、原地改写、执行面注入)以负例与排除句挡在条文外;知识否证有了不破坏 trace 的出口
- 坏:三仓需各一轮迁移施工(ai-ccoe 正名五动作、browse_rs 从零建、pve-harness 约 90 文件迁移),迁移期断链与豁免正则需接线;两 skill 文本面改动大(修订 22 项),文档即代码守卫与禁字门禁需全绿后过闸;字母表退役不复用律使既有混挂件(如 R002)须留档注记迁移
