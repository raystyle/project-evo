# ADR-0008:终态参考边界修订

## Context

ADR-0007 冻结 17 篇边界并规定增删参考须立新 ADR。总台派单(2026-09-16)两项治理沉淀:全平台连接姿势(WSL mirrored 回环纪律,入 env-platform 第十节,不动边界)与多仓飞轮协作协议(herdr 派单、回执、conclusion 自取、端点支撑;无既有篇可承载,base-init 管初始化、flow-archive 管档案,跨仓协作是独立主题)。本 ADR 是 ADR-0007 边界条款的首例显式修订。

## Decision

references 由 17 篇扩至 18 篇,新增 `flow-flywheel.md`（多仓飞轮协作:工位形态、派发自包含、回执 conclusion 自取纪律、端点测试支撑、吸收纠错分流）;ADR-0007 其余条款(五件套、17 篇清单中的存量篇目、supersede 纪律)不变。env-platform 增第十节「全平台连接姿势」为篇内内容修订,不动边界。

## Consequences

- 好:跨仓协作有标准承载,六仓四轮实证可复用;边界修订走了自己定的 supersede 纪律,首例闭环
- 坏:参考面加一篇,SKILL 路由与三层索引须同步(变更完整性成本);家族外采用者可裁定不启用多仓协作面 [假设]
