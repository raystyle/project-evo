# ADR-0005:三栈文档投影工具链体系补齐

## Context

dev-evo 的三栈机制对照(base-projection.md 对照表)自第五十批确立:Rust 走 /// 契约注释加 cargo doc 与 aidoc,Python 走 docstring 与 MkDocs,TypeScript 走 TSDoc 与 API Extractor。references 工具篇此前只有 tool-rust.md 与 tool-typescript.md,Python 篇缺失,三栈体系不齐;家族三仓(hst_rs 与 ark_rs 为 Rust、ohmycloud 为 TypeScript)已各自落地,Python 面由本仓 PEP 723 脚本实践承载。用户 2026-09-16 裁定:在文档即代码结构基础上形成三栈 ADR 项目体系,并把已沉淀的研究与日记机制固化入册,随后封版。

## Decision

补齐 tool-python.md(uv 运行时与 PEP 723、docstring 契约、MkDocs/Griffe 投影、pytest 与 doctest 门禁),references 三栈工具篇齐;新增 flow-archive.md 把 diary 一天一篇与 research SNNN 编号、六态、择要升 ADR、结构保留红线固化为专篇;base-projection 对照表下补 Python 侧管线段;SKILL 意图路由与 references README 索引同步(18 篇到 20 篇)。

## Consequences

- 好:三栈对照表三列各有落地篇,AGENTS 合同「按栈选投影工具链」有完整检索面;档案机制从散落(base-init 验收项、super-research 管线、exp-sedimentation 沉淀链)收拢为专篇
- 坏:Python 投影链(MkDocStrings、interrogate)在本仓未实装,篇内标 [推断],首个 Python 重文档仓落地时需回填实证 [假设]
