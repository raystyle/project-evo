# S013:研究形态与工具链范式对照

> 信源:pve-harness 与 clean-chrome 两仓研究档案实践(2026-10-09 快照),加本机 repos 下 project-evo、clean-chrome、ai-ccoe、ark_rs、browse_rs、prs_c2coe、prs_c2coe-vulscan、OfficeCLI、zvec-grep、oxvg 工具链扫描(同日)。对照对象:本仓 evo-doc:doc-gov。用户裁定(2026-10-09):一,doc-gov 定形四文档形态(COE 三层聚合双链、项目日记、研究、ADR);二,不同项目用不同文档结构治理,只有合适的、没有硬性。信源点名止于本档案。

## 研究形态公因式（三仓对照）

- 命名:S 加三位编号加连字符长主题,文件名即标题;编号接当前最大号、退役不复用;目录 docs/research/ 带 README 索引表
- 粒度:一题一篇 30 至 80 行高密度;研究先行(动手前立档,实现后回填验证节);台账型变体(追加节加后续义务图)承载跨日推进
- 结构:H1 加引块元信息(信源与快照、关联编号、用户裁定、六态总括)到背景、过程(证据命令行号)、结果、关键结论(逐条六态)、参考;对照类加对照分流三桶
- 六态标记是灵魂:结论断言不标六态视为未完成 [实证: 三仓规范条文与门禁核对]
- 互链靠编号文本不靠超链接;rg 全文直搜为主力,README 速览表允许滞后 [实证: 三仓 grep 零超链接命中]
- 手写随 git 提交,与 CHANGELOG 正交(CHANGELOG 只记版本级里程碑) [实证: 三仓 git log 与 CHANGELOG 头部纪律核对]

## 工具链范式核心（十仓扫描）

- 工具归档目录(.tools/ 或 tools/)进 git,带 README 清单表(脚本、用途、调用方),新增或改动同步登记
- python 脚本 PEP 723 内联元数据 uv run 直跑,不建 venv;零依赖默认,带依赖是例外给理由(仅 ai-ccoe catalog-bump 一例带 pydantic 与 tomlkit)
- 门禁三态退出码 0 过、1 违规、2 出错;路径级豁免走环境变量正则;根三件永不豁免
- md 禁字规则唯一权威单文件,check、scan、hook 多面同源 import
- 提交挡板 core.hooksPath 指钩子目录跑门禁(project-evo 与 clean-chrome);无 hooks 仓退化为 AGENTS 裸命令纪律加 CI
- AGENTS 五节合同加 CLAUDE.md 桥;发布三段式加 sha256 边车;版本载体唯一权威,载体外版本号即第二真相
- 分化项:目录名两派、python 下限(3.11 对 3.12 新旧线)、hooks 强度、测试框架(pytest、vitest、cargo test、node、无)、文档门禁层级(PE 编号制、mdcharlint、双链图) [实证: 十仓逐仓实查]

- 真新增吸收:研究档案形态成文 base-research.md;工具链范式成文 tool-project-kit.md;SKILL 意图路由与形态速览、四形态口径、版本载体 0.5.2 六面同步
