## distil 四步环指导(产出物 = hook rule 件)

- 一轮 = 蒸馏加提案加闸门;角色三分(执行者/蒸馏者/提案者),单 agent 连任以回合为界换帽;一轮只出一案
- 执行:每轮开工先点名「当前标准盖不住的失败义务」(载体 = 项目既有台账,不另立平行清单);没有点名义务不开环
- 蒸馏:有限样本(失败为主至多 5、成功为辅至多 3,窗口缺省近 1 至 3 日);禁改 sources 与 operations;不发明轨迹不支持的模式;蒸馏完即提交 knowledge git(先于提案,拒绝不回收)
- 提案三选一恰好一案:`create` = 新标准 hook rule 件(frontmatter patterns/match + 注入正文,目的说明链到支撑模式页);`patch` = 改既有件锚定操作(append/replace/insert_after,锚点缺失即败);`no_action` = 证据不足合法出口,不跑闸不动标准集;缺提案文件是事故
- 闸门:合取三条全过才提交标准集,任一不过回滚,提案全文进防重提页
- 停机:无未覆盖失败义务或连续 no_action 即停;成本纪律:蒸馏样本个位数,验证只跑合取谓词点名义务
