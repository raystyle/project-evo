# shares - evo 文件域原语

**定位**:五原语的文件域:S3 形中转看板,引擎 s5,内容哈希键。共享面在 `../agents/references/`,本篇只持域面。

## 动词面

| 动词 | 义 |
| --- | --- |
| `view` | share/ 前缀键表 |
| `put <文件>` | 上架,回显键 |
| `get <键> [-o\|--output 名]` | 取回(缺省存键尾文件名) |
| `to <id> <文件> [--force]` | 定向交付 = 上架加信封知会 |

- 裸调用 = view,exit 0;全局旗标与文法见 `../agents/SKILL.md` 二节

## 语义

- 键形:`share/<源机>/<内容短哈希>/<文件名>`;同内容命中同键,不同内容不互覆
- DELIVER:先上架再投信封 v2,取用行 = `s5 get -o <文件名> <键>`;域字段 key 与 name
- 拒投:文件已在键上、代记注明待达,人不丢件;`--force` 重发或改约
- Windows 端无本地 s5 时走 WSL 代役,路径自动互转

## 惯例与坑

- 大内容走本域上键,流里只放键引用(streams 域配合)
- 版本链传件:消息里带键与 sha 两写并存(键 = 取用面,sha = 验证面)
- ack 惯例:文件件可回执 ack 键(shares 上 share/<名>/…-ack.txt)
- 取回指定落名用 `-o`,免键尾名撞本地件
