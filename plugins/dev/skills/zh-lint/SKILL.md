# zh-lint - evo-lint 简明技术中文静检

**定位**:受控中文写技术内容,读者读一遍就不会读错。规则 = 简明技术中文规范(六节四十条,词表三张表),上游仓为活权威;本 skill 蒸馏速览 + 机检工具,不 vendor 规则全文。

## 一、适用与不适用

- 适用:操作手册、安装部署、故障排查、接口与参数说明、技术概念解释、AI 解释性回答、工作汇报与任务回执、界面提示与错误信息
- 不适用:营销文案、叙事评论、法律原文、代码与机器可读内容(原样保留)

## 二、写前先分类

- **操作句**:指示读者执行动作,编号步骤里动词开头,不超 30 字
- **描述句**:其他句子,不超 40 字
- 字数算法:汉字 1、英文单词或数字串 1、行内代码段 1、标点不计

## 三、必须规则速览（六节精华）

| 节 | 必须条 |
| --- | --- |
| 词 | 一概念一词(1.1);词表限定义(1.2);不用禁用词(1.3);不用进行加加以加作出加予以(1.4);程度词必须带数值(1.5);缩写首现全称后固定(1.6);不用黑话空泛词(1.7) |
| 句 | 操作句 30 描述句 40 字(2.1);一句一事(2.2);操作句祈使动词开头,不写请您用户需要(2.3);主动句写出执行者(2.4);条件在动作前(2.5);最多一个否定(2.6);定语不超 15 字(2.7);指代只指上一句(2.8);不用反问感叹(2.9) |
| 段 | 一段一主题首句点明(3.1);一段不超 6 句(3.2);步骤编号列表并列用符号,正文不串联(3.3);列表各项结构一致(3.4 建议);不用「等」开放列举(3.5) |
| 步骤 | 一步一动作(4.1);预期结果另起一句写动作后(4.2 建议);警告独立成段放步骤前三件事(4.3);区分人动作与系统行为(4.4);前置条件单独列出(4.5);步骤里不解释原因(4.6 建议) |
| 数字 | 阿拉伯数字与单位空格(5.1);范围写明含端点,不用以上以下以内(5.2);不用相对时间(5.3);操作句参数说明不用估计词(5.4);倍数百分比固定写法(5.5) |
| 术语 | 首现全称加括注;一词一义;项目专有术语入项目术语表 |

完整四十条与判例见 `references/stc-rules.md`;词表三张表(禁用词、选词、一词一义限定)权威在上游仓。

## 四、工具

```bash
uv run <技能根>/scripts/zh-lint.py <文件...> [--wordlist <词表.md>] [--strict]
```

- 内置先验核:无条件低误报的禁用词(进行、加以、予以、作出、做出、报错、缺省、登陆、阀值、赋能、闭环、沉淀、痛点等)与选词(单击改点击、删掉改删除等)
- `--wordlist` 外接上游词表全表:自动检查列收条目,编号项内条件(然后、并且)与操作句条件生效
- 句长机检:按句末标点拆句,编号列表行按操作句 30 字限,其余 40 字限
- 退出码:0 无发现、1 有发现;只报不改;行内代码内容不参检

## 五、汇报面速览（AI 回答与回执）

- 适用:工作汇报、任务回执、排查结论、请示决定;详细规则与五模板见 `references/reporting.md`
- 结构律:第一句 = 结论或状态(状态词十词:已完成、部分完成、未开始、进行中、已验证、未验证、失败、跳过、阻塞、未确认)
- 验证状态:已验证写方法与命令与输出摘要;未验证写原因与影响;说结论必说证据等级(六态的回复形)
- 询问律:首句直接问题;选项编号,每项一行含代价与后果
- 语言律增量:情态动词只用必须、不得、可以;开头不用缓冲语;不用比喻成语拟人

## 六、模式与分工

- 常规模式(默认):必须条 + 词表自动检查条;建议条人工酌情。严格模式:全部条
- 与 md-lint 分工:md-lint 管 skill 格式、禁字、断链、行数;zh-lint 管语言清晰度(用词与句式);两者可同跑
- 权威入口:简明技术中文规范 0.2 与词表(github.com/mzopedia/simplified-technical-chinese,规范 CC-BY 4.0);规则演进以上游为活权威,本 skill 蒸馏页随批同步
