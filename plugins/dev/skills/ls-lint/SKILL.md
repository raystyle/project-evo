# ls-lint - dev 类型化项目结构标准

> 闸门记录(轮 1,2026-10-11,用户立项令 evo-03):门禁当轮实跑无回归(pytest 28、check 12/12、scan 干净、六加一 skill 断链 0);点名义务「项目结构标准只有本仓单形 init,无类型面无声明式规则」从缺翻转为有(ADR-0022、REQ-020);本页链 knowledge 无(标准源仓),链依据 = ADR-0022 与四仓实形判例。促成本技能的依据:同日结构研究档与四仓终态。evals 触发用例集见 [references/evals.md](references/evals.md)。

**渐进知识库型 skill**:本文件只做意图路由与两面速览,类型模板与规则形在 references 与 templates。

核心思想:**结构是声明出来的,不是约定出来的**。每类型一张标准结构卡(目录树加必备件加生成物位加配置根件位),init 按卡补位,check 按卡比对;豁免带因由登记,不静默。

## 一、意图路由

| 意图 / 你要做的事 | 参考 |
| --- | --- |
| 看四类型标准结构卡(TS CLI、知识三层、worker 服务、Python 工具) | `references/types.md` |
| check 面:声明式规则形、豁免与本地覆盖 | `references/rules.md` |
| init 面:按类型脚手架走法 | `references/rules.md` 第二节 |
| 规则件本体(toml,四类型) | `templates/*.toml` |

## 二、两面速览

- **init 面**:选类型,按 templates 卡比对现仓,既有件不动、缺件补位(目录、README、AGENTS、配置根件、生成物占位带声明头);三层聚合类型联动 distil-skill 建仓五步
- **check 面**:按类型规则件逐节比对(必备件在位、生成物位不手改、禁入位不入源码树、配置根件一工具一件、可选成员位形态正);红项逐条报错与修法;豁免走本地覆盖文件登记在册

## 三、纪律(速览)

- 类型卡是标准投影:改卡走本仓治理(REQ 加 ADR),不仓内私改规则件
- 存量仓结构迁移不自动施工:出差距清单,迁移走该仓自己的蒸馏环与施工单(判例:今日五仓)
- 判定沿 lint skill 纪律:退出码制、逐条修不豁免凑绿
