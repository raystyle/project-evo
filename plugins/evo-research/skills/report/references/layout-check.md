# 版式复检口径

> PDF 是二进制产物,agent 与轻量终端都看不到版式;复检 = 把每页转成可看的图 + 给出可量化的行距与留白度量,让排版问题可以被检查而不是靠猜。

## 一、口径

- **逐页转图**:PDF 每页转 PNG,落 `.preview/<报告短名>/page-N.png`(可加 index.html 滚动预览)
- **行位置与行距**:以页内墨迹行(灰度低于阈值算有墨,连续有墨合并为一行)测每行的纵向位置,得行距序列
- **异常判定(启发式)**:以该页正文行距中位数为基准,行距小于 0.5 倍记「偏挤」,大于 2.5 倍记「偏空」;这类异常常对应粘连的段落、误设的段距或多余空行
- **左右留白**:每行的水平起止度量留白,异常窄/宽的行提示表格溢出或错误缩进

## 二、工具形态(知识面,下游自建)

- 参考实现形态:pypdfium2(>=4.0)逐页渲染 + pillow(>=10.0)灰度分析,纯只读不改进版
- 带外部依赖,不合本仓脚本零依赖惯例,以本篇口径为准,下游仓按需实现
- 典型用法:`检查 <报告>.pdf --pages 1-3` 只查指定页;`--html` 追加预览页

## 三、坑(实证)

- **只看抽取文本判断版式必翻车**:文本层全对,版式可能已乱(粘连、溢出、空行成段);版式结论必须来自转图或度量
- 版式参数只改渲染模板,不在报告里做局部排版;复检发现异常先回模板或 md 结构,不手改 PDF
