# 甲面:CLI README 标准

> 研究基线:四业界标杆(ripgrep、fzf、bat、fd)README 实读提炼;人类阅读优先,agent 面另见 agent-face.md。骨架模板在 templates.md 第一节。

## 一、研究结论(四标杆共性)

| 共性 | 四标杆实证 |
| --- | --- |
| 头部:H1 加徽章(CI 状态、版本、许可) | 四家全有,徽章三枚内为宜 |
| 特性与演示前置(features 加 screenshot/demo/benchmark) | 全有:rg 对比表、fd 渐进示例、bat 语法高亮演示 |
| 安装:按平台逐条命令块,从主流包管理器到源码构建 | 全有且极全(15 至 22 个平台小节) |
| 配置:配置文件专节(带注释完整样例)或环境变量表 | bat 专节加样例、fzf 环境变量族、fd 忽略文件 |
| 使用:教程式渐进示例(任务型小节,简到繁) | fd 与 bat 的 How to use 为范式 |
| 与其他工具集成:可拷配方块 | bat 与 fd 各五项以上 |
| 排障:问题加对策小节 | bat 与 fd 有专节,rg 走 FAQ 外链 |
| 尾部:开发/贡献/维护者/安全/许可 | 四家全有,许可恒在 |

## 二、四节主骨架(定稿)

1. **项目介绍**:H1 加徽章;一句话定位(是什么、替代谁、为何快或好);特性列表(短句,一条一能);演示(screenshot 或可拷命令输出);何时不用(边界诚实,rg 范式);基准或对比表(有实力差距才放)
2. **部署**:安装按平台逐条命令块(主流包管理器优先,源码构建殿后);升级一节(自升级或包管理器口径);二进制发行版给校验命令
3. **配置**:配置文件专节(路径两制、格式、带注释完整样例);环境变量表(名、作用、默认);忽略文件类若适用
4. **使用**:教程式渐进示例(任务型小节,从最常见任务到进阶);与其他工具集成配方;完整选项不内联,指向 `--help` 与 `--llms` 手册面

可选尾节(按需):排障/FAQ、开发与构建、贡献、维护者、安全报告、许可(恒有)、翻译链接。

## 三、写法纪律

- 示例驱动:每个特性配可拷命令块,输出用注释或引用块标注
- 渐进:先最常见任务,后进阶;读者三分钟内跑通第一个命令
- 提示块用平台 alert 形(`[!TIP]`、`[!NOTE]`、`[!IMPORTANT]`、`[!WARNING]`),不手拼装饰
- 配置给完整可拷样例(注释齐),不写残缺片段
- 选项与子命令全集不进 README(第二真相漂移面),指 `--help` 与 `--llms`
- 徽章三枚内;荣誉与赞助类内容尾置,不占首屏
- 锚点目录:节多于八个时给(Table of Contents)

## 四、反面清单

- 空营销话(「强大」「优雅」无实证)
- 内联全量 help 输出(维护漂移)
- 首屏放赞助或周边
- 无安装命令的「参见官网」式外推
- 配置只给键名不给样例
