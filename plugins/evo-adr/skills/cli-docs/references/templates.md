## 三、信封 schema 模板

```json
// 成功:<tool> --json
{ "ok": true, "data": <载荷>, "meta": { "command": "<命令>", "duration_ms": 0 }, "hints": ["<下一步建议>"] }
// 失败:stdout 无输出,stderr 单行
{ "code": "<错误码>", "message": "<人读信息>" }
```

| 项 | 约定 |
| --- | --- |
| `--format` 族 | `<人读形>\|json\|jsonl`,`--json` 为 json 简写,互斥 |
| jsonl | 列表逐行对象,无信封 |
| 退出码 | 0 成功;1 业务未命中;2 用法与系统错误 |
| 字段序 | 与人读行序一致(保插入序) |
| 裁剪 | `--filter <点路径>` 先,`--fields <逗号列>` 后 |
