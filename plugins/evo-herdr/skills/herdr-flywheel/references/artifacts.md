# 产物契约与状态档(跨窗格交流文件化)

> 所有跨窗格交流的产物与状态落统一标准路径的 md 文件:**盘上是确定稳态,herdr 生命周期态只是干预检查的信号**。本篇管路径、分型、三件套模板、状态档检查点与判读矩阵;四步协议条文在上级 SKILL.md。

## 统一标准路径

- 根 = 系统临时目录下固定名 `herdr-flywheel/`:bash 侧 `${TMPDIR:-/tmp}/herdr-flywheel/`;pwsh 侧 Windows 用 `$env:TEMP\herdr-flywheel\`,Linux 的 pwsh 无 TEMP 变量,回退 `/tmp` 与 bash 同 [实证: 2026-10-10 本机 /usr/bin/pwsh 实查]
- 每轮(轮次)一子目录,名 = 日期加主题短名(如 `2026-10-10-归属周知`),子目录即本轮交流总档;同机各窗格共享文件系统,路径直读直写,跨机面见文末
- 每笔交流一个单号(发起方自定短标识加两位序号,如 `fleet-01`),三件套如下;并行轮各笔各自成套,无共享文件冲突

| 文件 | 谁写 | 管什么 |
| --- | --- | --- |
| `<单号>-brief.md` | 发起方 | 发起笺:契约(任务清单、逐件验收判据),验收以此文件为基准 |
| `<单号>-state.md` | 接收方 | 状态档:agent 自报稳态,按检查点更新,状态检测看这里 |
| `<单号>-receipt.md` | 接收方 | 产物笺:逐件对账与证据,产物验收看这里 |

- **原子写**:先写 `<名>.md.tmp` 再改名落定,防对端读到半文(沿 lane 台账纪律)
- 两层账分清:本篇三件套管「这笔交流」(临时目录);并行义务台账管「整轮还欠什么」(总台仓内轮次档,见 parallel.md),互不替代
- 临时目录不承诺长存:轮次收尾择要吸收进仓(证据与标准文本),档本体可弃

## 交流分型

| 型别 | 判据 | 文件化 |
| --- | --- | --- |
| 任务型 | 要产出、有验收判据(改仓、跑门禁、提交) | 三件套 |
| 委托型 | 委派核查、评审、调研,要结论回执 | 三件套 |
| 同步型 | 周知通报(归属、标准变更),要留痕确认 | brief 加 receipt;state 简记(已接后直接已交) |
| 讨论型 | 征求意见、纯交流,不落仓 | 不文件化,屏读加吸收 |

发起方不限总台:任何窗格 agent 都可发起任务、委托、同步,接收方照三件套走;总台只是飞轮轮次里的常设发起方特例。

## 发起笺 brief

- 笺头:单号、型别、发起方、接收方、时点、轮次档路径
- 任务清单:逐件编号,一件一句可判
- 验收判据:逐件给「过、缺、不适用」三态判据,附标准权威路径(判什么、去哪查)
- 回执要求:状态档与产物笺的目标路径、逐件对账指令
- **判据在派发时固化**:验收基准以笺为准,接收方对判据有异议在「已接」检查点前提出,过后按笺对账,防事后移动门柱

## 状态档 state

接收方按检查点自写,每点一次原子写:

| 检查点 | 含义 | 必记 |
| --- | --- | --- |
| 已接 | brief 已读且任务无歧义;有歧义即回问,不写已接 | 时点 |
| 在办 | 正在执行 | 当前步骤、心跳时点 |
| 候裁 | 等人裁(审批、问询、方向选择) | 等什么、等谁 |
| 已交 | receipt 已落档 | receipt 路径 |

- 缺项如实报「未记录」,不猜不编(沿探针契约纪律);心跳判据 = 状态档 mtime 或心跳行时点
- 零改动完成合法:照走已交检查点,receipt 记零改动与一句理由

## 干预矩阵(herdr 信号乘盘上稳态)

herdr 生命周期态(idle、working、blocked、done)是实时干预信号,不进验收判据:

| herdr 实时态 | 盘上状态档 | 判读与动作 |
| --- | --- | --- |
| working | 在办 | 正常在跑,不干预 |
| idle 或 done | 在办 | 疑停摆:agent read 实查屏幕后再动,不盲催 |
| working | 已交 | 在跑别的单,本单验收不受影响 |
| blocked | 候裁 | 等裁定:read 看 UI 问用户,不代答 |
| 任意 | 心跳久未动 | 停滞:按租约纪律处置(parallel.md) |

门控用信号、判定用稳态:派单时机门控(SKILL 派单节)仍用 herdr agent get 实时态;完成与在办判定一律以状态档加产物笺对账 [实证: 2026-10-10 邻居窗格轮 prompt --wait 提交即返报 done,不信信号查盘上,状态档已交三检查点齐,信号与稳态终吻合]。

## 产物笺 receipt

- 笺头:单号、接收方、时点、brief 路径
- 逐件对账表:件号、三态(过、缺、不适用)、证据(commit sha、门禁退出码、文件行号引文);证据自取自跑,对方陈述不作数(沿 SKILL 回执节)
- 未尽事项与偏离说明;产物本体过大不内联,receipt 记产物路径与验收结论
- 会话回复只发 receipt 路径加一句摘要;全文在盘上,屏读是回退

## 跨机细则

- 盘上文件只在本机可直读:跨机派单时 brief 全文随 prompt 内联(沿 SKILL 跨机周知:prompt 自包含够不到的路径),receipt 全文随回执内联,本机文件只作底稿与对账锚
- 跨机周知(同步型)双侧都留回执:各收件工位在自己机器各写各的 receipt,发起方以回执文本对账

## 与官方 herdr 口径的分野

官方 herdr --skill 对文件回执的口径是「仅兜底,初版派单不预设文件输出」,那是通用 agent 操作的保守缺省;本飞轮协议在任务、委托、同步三型上升格为恒文件化,分野有意为之,飞轮辖域内以本篇为准,讨论型仍守官方缺省。
