# 双道选型、命令面与凭据纪律

> 命令面按 s5-01 立项设计写,**候 s5 首版实测定稿**;实测偏差以本机 `s5 --help` 为准回填。

## 一、选型判据(什么内容走对象什么走流)

三问定道:

| 问 | 对象道(文件,S3 形) | 流道(记录,S2 形) |
| --- | --- | --- |
| 内容有终态吗 | 有(写完即定稿:三件套、工件包、研究档、release 资产) | 无(持续追加:轨迹流、事件流、日志) |
| 消费形态 | 整取(get 一次拿全) | 消费尾(tail 最近 N 条) |
| 写入模式 | 一次写(put 覆盖同键) | 多次追加(append 顺序保序) |

三问全偏对象即对象道,全偏流即流道;混合内容(如轮次档:三件套是对象、进度是流)拆开各走各道,不硬塞一道。大件(超 MB 级)即使追加形也走对象道按版本键(流道为小条高频设)。

## 二、命令面(候定稿)

- 文件道:`s5 put <本地路径> <远端键>`;`s5 get <远端键> <本地路径>`;`s5 ls <前缀>`;`s5 del <远端键>`
- 流道:`s5 append <流名> <内容>`(stdin 形候定稿);`s5 tail <流名> [-n N]`
- 键空间约定见 fleet.md(轮次档、研究档、轨迹流各有规范段);生产桶 herdr-flywheel 由总台管钥
- 后端:文件道 garage(path-style);流道 s2 streamstore(basin 与 stream 形候 s5_rs 调研定稿回填)

## 三、零感知凭据的 agent 侧纪律

- **三不**:不读配置文件(路径都不探)、不写配置、不回显(输出与日志里凭据字段零出现)
- 命令面零凭据参数:任何 `--key`、`--token`、`--endpoint` 形参数不出现(端点也收配置层,agent 不指定)
- 凭据失效症状(403、超时)上报人类或总台处置,agent 不换钥不自修配置
- 配置文件 0600、不进 git;scan 门禁辖凭据面,见即红
