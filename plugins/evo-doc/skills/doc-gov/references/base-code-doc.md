# 代码 doc 注释与文档即代码

> doc-gov 治理面:注释是公开契约的就近投影,文档是代码的生成投影;单一权威源,投影不手改。

## 代码 doc 注释(契约注释)

- 公开项(公开函数、类型、命令、配置面)的注释即契约:签名加 docstring 说 what(参数、返回、失败面、副作用),消费方据此调用
- **改公开项同步契约注释与测试,同一次提交**:只改行为不改注释即变更不完整
- what 进注释,why 进 ADR:缘由与取舍不塞函数注释;坑与修法进执行轨迹(见市场技能 `evo-skills:distil-skill` 轨迹篇)
- 注释密度跟仓内惯例,不追全覆盖;内部私有项从简
- 生成物内的注释随生成器改,不手改

## 文档即代码

- **单一权威源**:标准条文只在权威文件(源码契约注释、ADR、skill 本体),README、手册、--llms 面都是投影;发现第二份真相即删或降为指针
- **投影可再生成**:手改投影即漂移;守卫进门禁(文档断链扫描、CLI 手册与帮助面漂移守卫,见 tool-project-kit.md 门禁面)
- **生成优于维护**:可从代码生成的面(命令树、配置表、schema)一律生成,禁手维护第二份
- 门禁挂接:投影检查红态不进提交(与工具链范式的提交挡板同挂接点)
