# 项目日记:一天一篇的活轨迹

> 过程留痕形态:当日用户令、裁定、坑与门禁实录,一天一篇,过程不改写。是 ADR 与 REQ 的素材池,择要升格;COE 仓挂 diary 做活轨迹。

## 形态

- 文件名 `YYYY-MM-DD-主题.md`,一天一篇;初始化当天记首笔
- 篇首引块记当日用户令原文与当日闭环概览
- 正文分节:裁定(逐条编号,记档为常例)、坑(实档,含修法与预防)、门禁退出码(不贴全输出)、终态(当轮交付面:版本、提交、分发)
- 过程性文档不改写;存量禁字走路径级豁免通道,历史留痕

## 分工与升格

- 过程进日记;不可逆决策升 ADR;需求与验收升 REQ;持久结论升 COE knowledge 页(带 sources)
- 日记是素材池:二犯的坑、反复的裁定,升格后日记留档不删
- 与 agent memory 分工:偏好与临时约束走 memory,事实轨迹进日记

## 增强面(ADR 之外的加强)

- 篇首引块固定形:日期加用户令原文加当日闭环句,读首行即得脉络
- 裁定条编号,可被后续日记与 ADR 引用(「某日裁定 N」)
- 坑条记修法与预防,不止现象;门禁记退出码与判据
- 终态节收口:当轮版本、提交、分发一目了然,封版与复盘从这里取材
- 检索面:文件名即索引(日期加主题),rg 按主题词直达当日篇

## 与其他形态的衔接

- ADR/REQ 仓:diary 落 `docs/diary/`,一天一篇,骨架同上
- COE 仓:diary 落仓根 `diary/`,与 knowledge 互补:日记是活轨迹,knowledge 是沉淀结论
- 日记不替代档案:研究级证据进 COE sources 或独立 research 档,日记只留过程
