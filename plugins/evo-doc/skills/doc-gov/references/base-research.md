# 研究档案:一题一篇的对照与结论

> 纯项目记录形态:课题级研究过程、证据与对照结论,S 编号一题一篇,信源点名止于本档。是 COE sources 与项目日记之间的证据层,持久结论择要升格。

## 形态

- 文件名 `SNNN-主题.md`,文件名即标题,连字符断句;编号接当前最大号,退役不复用
- 篇首引块记元信息:信源与快照时间、关联编号(REQ、ADR、S)、用户裁定、六态总括
- 正文分节:背景(课题与动机)、过程(命令、环境、行号级证据)、结果(数据与摘录)、关键结论(逐条六态标注)、参考(来源与本地路径)
- 对照类研究加对照分流节:等价不吸收、真新增吸收、留档,三桶显式分流
- README 登记表必登记(编号、文件、主题、状态);rg 全文直搜为主力,速览表允许滞后

## 分工与升格

- 课题证据进研究档;日记记当日过程,研究档记课题全程
- 持久结论升 COE knowledge 页,sources 指回研究档;核验结论可作 REQ 的 trace 证据
- 吸收即提炼:进库知识面只留最准确精练的可复用表达,成品不点名外部仓库,信源点名止于研究档

## 增强面

- 六态强制:关键结论不标六态视为未完成,禁止把没验证写成已验证;悬空中转态收尾必处置
- 互链靠编号文本不靠超链接;文件名即检索面,rg 按主题词直达
- 研究先行:动手实现前立档,实现后回填验证节(勾选清单加实证标注)
- 台账型变体:追加节加后续义务图承载跨日推进,终态节收口
- 手写随 git 提交,与 CHANGELOG 正交(CHANGELOG 只记版本级里程碑)

## 与其他形态的衔接

- ADR/REQ 仓:research 落 `docs/research/`,骨架同上
- COE 仓:研究档作 sources 层输入,双链指回;日记只留当日过程,研究级证据不进日记
- 归档后不改写;退役编号在索引留占位

## 选型

- 只有合适的、没有硬性:已有同构覆盖的仓(如编号制方案归档加坑库体系)不必引入
- 适用判据:仓里有真实调研、上游核验、选型对照发生,研究档才值得立
