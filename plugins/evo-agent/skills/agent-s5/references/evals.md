# agent-s5 触发用例集(五条三类,候定稿期同样适用)

> evo-02 纪律:隔离会话私有 config dir 只挂候选集;应触发与近失同会话序贯,含糊独立会话;fail 映射进合取三条,二值不打均值。

## 应触发

1. 「跨机飞轮轮次开始了,把这份 brief 和后续三件套共享给 lan-ubuntu 上的工位」(跨机轮次档,对象道加路径规范)
2. 「把这条轨迹要点追加到本仓的跨机事件流,再取最近二十条看看」(流道 append 加 tail)

## 不应触发(近失)

3. 「给同机隔壁窗格的工位发个任务单」(同机共享:本地文件系统与 herdr 派单即达,s5 不上;且任务派发是 herdr 信号面)
4. 「通知远端工位我这边收束了,顺便看它现在什么状态」(消息与状态:herdr 管信号,s5 只管内容,不混道)

## 含糊边界(独立会话)

5. 「把这个 200MB 的构建产物给 lan-mac 那边的仓用一下」(大件一次性跨机传输:对象道临时键加消息道告键加用毕 del 是 s5 面,但「给对方仓长期用」则涉对方仓自己的工件归档面;判定看回答是否分清「传输即弃」与「归档留位」两形)
