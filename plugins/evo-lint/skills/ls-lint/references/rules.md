# 声明式规则形、check 与 init 走法

## 一、规则件形(toml,ls-lint 同族声明式)

每类型一文件(`templates/<type>.toml`),六节:

| 节 | 语义 | check 判定 |
| --- | --- | --- |
| meta | 类型名与判例源 | 不检查 |
| required | 必备件 | 缺任一即红,报缺件与修法 |
| generated | 生成物位 | 在位但头无生成声明即红(禁手改声明缺) |
| excluded | 禁入源码树 | 出现且未忽略即红(该进 ignore 或移出) |
| config-root | 配置根件位 | 错位(收进 config/ 等)即警告级,一工具一件原则 |
| optional | 可选成员位(apps、crates、tools) | 在位时形态错(如未自持清单、输出错位)即红 |

## 二、init 面(脚手架走法)

1. 判类型(问用户或按仓线索:语言面加形态面);拿对应 templates 卡
2. 比对现仓:既有件一律不动(init 不覆盖不迁移);只补缺件
3. 补位序:目录树先行,配置根件,门面件(README 加 AGENTS 加 CHANGELOG),生成物占位(头带「生成物,禁手改」声明),三层聚合类型联动 distil-skill 建仓五步(防重提页空态也要立)
4. 补毕跑该仓门禁;无门禁的新仓先立最小门禁(check 形按 lint skill)

## 三、check 面(结构 lint 走法)

1. 读规则件与本地覆盖(.ls-lint.toml 等位:可覆盖各节、豁免路径须带因由注释);豁免在册可查,不静默
2. 逐节比对(六节判定见上表);红项逐条输出:路径、节名、现象、修法一句
3. 存量仓不自动施工:产出差距清单交付,迁移走该仓自己的蒸馏环与施工单(判例:今日五仓迁移全部走单)
4. 判定纪律沿 lint skill:退出码制,逐条修不豁免凑绿

## 四、本地覆盖形

```toml
# .ls-lint.toml(仓根)
type = "ts-cli"            # 显式选型(覆盖自动判定)
[exempt]
"apps/legacy/" = "历史子工程,判例在 ADR-XXXX;待第三批迁移"
```

豁免须带因由(引用 ADR 或判例),无因由的豁免即红。
