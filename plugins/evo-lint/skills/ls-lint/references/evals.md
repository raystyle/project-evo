# ls-lint 触发用例集(3 至 5 条,随技能入库)

> evo-02 纪律首批适用件。两方各跑:提案者自跑候选态证据,判官复核;隔离会话私有 config dir 只挂候选集;应触发与近失同会话序贯,含糊独立会话;fail 映射进合取三条,二值不打均值。

## 应触发

1. 「新建一个 Python 工具仓,按最佳标准结构把骨架搭起来」(init 面,Python 工具类型)
2. 「检查这个 TS CLI 仓的目录结构是否符合标准:生成物有没有混进源码树、配置文件位置对不对」(check 面,TS CLI 类型)

## 不应触发(近失)

3. 「给这个仓的 markdown 做静态检查,修掉禁字和断链」(lint skill 面,非结构面:类型与规则件不涉)
4. 「把 docs 全家桶迁移成三层聚合,requirements 改 req」(distil-skill 既有仓迁移形:是层迁移不是类型脚手架或结构比对)

## 含糊边界(独立会话)

5. 「新仓要不要把知识三层放 docs/ 下面?」(结构咨询:涉及 ls-lint 的类型卡与 distil 的层根仓自选两可;预期触发 ls-lint 给类型卡,并指层根选择归 distil-skill 条文:判定看回答是否引两skill边界而非只答其一)
